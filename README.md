# 🕒 CronTask

CronTask é uma aplicação desktop desenvolvida em **C# com .NET (Windows Forms)**, criada para auxiliar no **registro de tarefas e no controle de tempo gasto em cada uma delas**.

O objetivo principal do projeto foi resolver uma necessidade pessoal: acompanhar o tempo que cada atividade demandava no trabalho. Além disso, serviu como prática para aprender mais sobre **C#** e **Windows Forms**.

---

## ⚙️ Funcionalidades

- Registrar tarefas com nome descritivo.  
- Iniciar e parar cronômetro para cada tarefa.  
- Salvar registros de início, fim e tempo total gasto.  
- Exportar os dados para **CSV**.  
- Carregar dados de **CSV** já existente.  
- Interface simples e objetiva em **Windows Forms**.  

---

## 🚀 Tecnologias utilizadas

- **C#**  
- **.NET (Windows Forms)**  

---

## 📂 Estrutura de Dados

Cada tarefa salva contém:  

- **NomeDaTarefa** → descrição da tarefa executada.  
- **HorarioInicio** → hora em que a tarefa foi iniciada.  
- **HorarioFim** → hora em que a tarefa foi finalizada.  
- **TempoGasto** → tempo total dedicado.
